# Cayley graphs and state transfer: data and code

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23925744.svg)](https://doi.org/10.5281/zenodo.23925744)

Data and [SageMath](https://www.sagemath.org) code accompanying

> A. S. Árnadóttir and K. Guo, *Perfect state transfer and Cayley
> presentations*, [arXiv:2608.20476](https://arxiv.org/abs/2608.20476).

The repository contains:

- every connected Cayley graph on 6 to 29 vertices, up to isomorphism, with
  the groups of which it is a Cayley graph;
- every connected vertex-transitive graph on at most 23 vertices that admits
  peak state transfer, with partners, times, exact amounts, and Cayley groups;
- the census of connected vertex-transitive graphs with perfect state
  transfer from the paper;
- code that computes all Cayley graphs of a given group, and code that tests
  for perfect and peak state transfer.

## Contents

### `data/cayley-graphs/`: all connected Cayley graphs, n = 6 to 29

Computed by Arnbjörg Soffía Árnadóttir. For each order n, the folder
`OrderNN/` contains

- `Ord<n>-g6.txt`: the graph6 strings of the connected Cayley graphs on n
  vertices, one per isomorphism class, one per line;
- `Ord<n>-GraphGroups.txt` (when there is more than one group of order n):
  the same graphs in the same order, each line a list `[g6, [i, ...]]`
  meaning that the graph is a Cayley graph of `SmallGroup(n, i)` in the GAP
  SmallGroups library, for exactly the listed i;
- `Ord<n>-GraphSet.txt` (when the cyclic group is the only group of order
  n): each line `[g6, S]`, with S a connection set in the cyclic group
  generated by `f`.

`NrOfGraphs.txt` gives the number of graphs for each order, and `Readme.txt`
shows how to read the files into Sage.

### `data/peak-st/`: peak state transfer on vertex-transitive graphs, n ≤ 23

Every connected vertex-transitive graph on at most 23 vertices was tested for
peak state transfer with respect to the adjacency matrix. The graphs on at
most 9 vertices were generated with nauty; the larger ones come from the
census of Royle and Holt,
[doi:10.5281/zenodo.4010122](https://doi.org/10.5281/zenodo.4010122).

Peak state transfer from u to v at time τ means that
|U(τ)<sub>v,u</sub>| = Σ<sub>θ</sub> |(E<sub>θ</sub>)<sub>v,u</sub>|, the
largest value this entry can take, where U(t) = exp(itA) and the E<sub>θ</sub>
are the spectral idempotents of A ([Coutinho, Guo and Schmeits,
arXiv:2505.11986](https://arxiv.org/abs/2505.11986)). The *amount* is
|U(τ)<sub>v,u</sub>|²; perfect state transfer is peak state transfer of amount 1.

For each order n with at least one example, `OrderNN/` contains

- `Ord<n>-g6.txt`: the graph6 strings of the graphs with peak state
  transfer, one per line;
- `Ord<n>-peakST.tsv`: one row for each such graph and each vertex v with peak
  state transfer from vertex 0 to v. By vertex-transitivity this describes
  every pair. Vertices are numbered as in the graph6 string.

| column | meaning |
|---|---|
| `graph6` | the graph |
| `n`, `k` | number of vertices, valency |
| `charpoly` | characteristic polynomial, factored over Q |
| `groups` | every group of which the graph is a Cayley graph, as `(n,i):structure:ab` or `:nonab` (GAP SmallGroup id and structure description); `-` if the graph is not a Cayley graph |
| `partner` | the vertex v |
| `tau` | the least positive time of peak state transfer from 0 to v |
| `amount` | exact amount, an element of Q(√D) written so that Sage can read it |
| `amount_approx` | the amount to 10 decimal places |
| `pst` | `yes` if the amount is 1, that is, perfect state transfer |

`summary.tsv` gives, for each n, the number of connected vertex-transitive
graphs, how many of them are Cayley graphs, how many admit peak state
transfer (split into Cayley and non-Cayley), and how many admit perfect state
transfer. In total, 430 graphs admit peak state transfer; 33 of them are not
Cayley graphs; and 38 admit perfect state transfer.

### `data/pst-census/`: the perfect state transfer census of the paper

The files published with the paper, unchanged:

- `pst-census-2-30.csv`: label and graph6 string of each of the 91 connected
  vertex-transitive graphs on at most 30 vertices with perfect state transfer;
- `pst-census-32.csv`: the 344 graphs of the partial census on 32 vertices
  (valency at most 12, complete only up to valency 11).

The labels are those of the appendix of the paper, which also gives the
spectrum of each graph.

### `code/`

| file | purpose |
|---|---|
| `cayley_graphs.sage` | `cayley_graphs(o, i)`: all Cayley graphs of `SmallGroup(o, i)` up to isomorphism, each with a connection set; `cayley_graphs_of_order(n)`; `is_cayley_graph_of(X, o, i)`. Exhaustive over inverse-closed subsets, so practical while G has at most about 20 pairs {g, g⁻¹}. |
| `qwalk.sage` | spectral decomposition and basic quantum walk utilities |
| `peakST.sage` | test for peak state transfer (spectral characterization of arXiv:2505.11986) |
| `pst.sage` | test for perfect state transfer |
| `peakst_census.sage` | regenerates `data/peak-st/` |
| `check_cayley_data.sage` | checks `data/cayley-graphs/` against `cayley_graphs.sage` |

Example, run from `code/`:

```
sage: load("qwalk.sage"); load("peakST.sage"); load("pst.sage")
sage: hasPerfectStateTransfer(graphs.CubeGraph(3))
(True, 1/2*pi)
sage: load("cayley_graphs.sage")
sage: D8 = cayley_graphs(8, 3)             # connected Cayley graphs of D8
sage: len(D8)
10
```

## Reproducing the data

```
cd code
# n >= 10 needs alltrans<n>.tar from doi:10.5281/zenodo.4010122 in VT_DIR
sage peakst_census.sage 2 23 VT_DIR ../data/peak-st
sage check_cayley_data.sage ../data/cayley-graphs 6 29
```

`peakst_census.sage` takes about five minutes on a laptop, and
`check_cayley_data.sage` about 40 minutes (most of it on orders 24 and 28).

## Checks

- The amounts are computed exactly, from exact spectral idempotents, and each
  agrees with the numerical value of |U(τ)<sub>v,0</sub>|².
- The graphs in `data/peak-st` flagged `pst = yes` are exactly the graphs on
  at most 23 vertices in `pst-census-2-30.csv`.
- For 6 ≤ n ≤ 29, `check_cayley_data.sage` confirms that `data/cayley-graphs`
  lists every connected Cayley graph exactly once, and that each group list
  is exactly the set of groups of which the graph is a Cayley graph. Every
  listed group is witnessed by an explicit connection set.
- A second method, which computes the regular subgroups of Aut(X)
  (Sabidussi's theorem), gives the same results for every graph on at most
  23 vertices and on 25, 26, 27 and 29 vertices, and for 1689 of the graphs
  on 24 and 28 vertices.
